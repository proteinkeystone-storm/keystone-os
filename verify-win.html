Authentifier un code de gain

Cette page permet aux commerçants partenaires de confirmer qu'un code WIN-XXXX-XXXX présenté par un client est bien issu d'un vrai gain enregistré. Vérifier ne consomme rien : vous pouvez le faire autant de fois que nécessaire. Quand vous remettez le lot au client, appuyez sur « Marquer comme utilisé » — le code restera authentique, mais il indiquera désormais la date de remise.
